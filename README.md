# Encyclopaedia

A local-first Android knowledge and competitive-exam study system.

Encyclopaedia is being designed tablet-first with an editable knowledge base, lessons, question bank, PYQs, image/PDF question ingestion, practice, revision, planning, analytics, backup/restore, and optional context-aware AI tutoring.

## Build

The Android application is built and tested with GitHub Actions. The normal debug build must not require private AI credentials.
